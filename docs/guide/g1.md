## A two-week plan

Ten working days take you from building the project to extending it. Each day reads one layer, traces it in the debugger, breaks it on purpose, rewrites one of its functions from blank, and ends with a deliverable that a test can judge.

The drills are numbered as in the sections below: Trace 1 to 8, mutation drills 1 to 24, rewrite drills 1 to 12. Read each day's module tab of this guide alongside its files: the tabs explain the code, this plan schedules it. A day is about six hours; if one runs over, move its last drill to the next morning rather than skipping the deliverable.

### Day 1: build, run, find your way

- Read: `README.md`, `CMakeLists.txt`, `tools/ci.sh`, `include/se3pf/types.hpp`, `tests/test_helpers.hpp`, `tests/rng_listener.cpp`, `tests/tube_fixture.hpp`, `tests/panda_fixture.hpp`; in `docs/DESIGN.md` the Conventions, Eigen pitfalls and Paper-to-code map.
- Drills: build Release and Debug (Trace drills, "Build for the debugger"); run `./build-rel/tests`, then `--list-tests` with a filter; set up `launch.json`; Trace 1 once in VS Code and once in plain gdb; create the drill copy with `git init` (Mutation drills, "How to run a drill").
- Deliverable: your own one-page table from each symbol of the Paper-to-code map (γ, ζ_γ, N, Ψ, η, ξ, J_Ψ, A, q*, X, β) to its `file:line`, and Trace 1's Panda N₀(0) printed in your own gdb session.

### Day 2: se3 and the metric

- Read: `include/se3pf/se3.hpp`, `src/se3.cpp`, `include/se3pf/metric.hpp`, `src/metric.cpp`, `tests/test_se3.cpp`, `tests/test_metric.cpp`.
- Drills: mutation drills 1 and 2, and the rows for `src/se3.cpp:53` and `src/se3.cpp:152` in "More verified mutations"; rewrite drills 1, 2 and 3.
- Deliverable: `Metric::Gamma` rewritten from blank, passing `./build/tests "Gamma is the derivative*"`, and two sentences of your own on why its translation block is exp(ω̂)ᵀ and not I.

### Day 3: paths and splines

- Drills: mutation drills 3 to 6; rewrite drills 4 and 5.
- Deliverable: `PeriodicHermite::eval` and `ConingCircle::velocity` and `acceleration` rewritten, passing `./build/tests "PeriodicHermite*,Tube: N'*,Lift: q*' between*"` and `./build/tests "coning circle*"`.

### Day 4: the tube, offline (Lemma 1)

### Day 7: the rigid-body example, end to end

- Read: `include/se3pf/rigid_body_example.hpp`, `src/rigid_body_example.cpp`, `apps/rigid_body_sim.cpp`, `tests/test_rigid_body_example.cpp`, `tools/plot_rigid_body.py`.

### Day 8: Panda kinematics, the lift and β

### Day 9: the Panda example, n = 7, and MuJoCo

- Read: `include/se3pf/panda_example.hpp`, `src/panda_example.cpp`, `apps/panda_sim.cpp`, `tests/test_panda_example.cpp`, `tests/test_controller.cpp:880-1213`, `docs/MUJOCO.md`, `sim/mujoco_panda.hpp`, `sim/mujoco_panda.cpp`.
- Drills: Traces 4 and 6; mutation drill 22; finish rewrite drill 12 for n = 7 (`./build/tests "Controller*,simulate*"`); the optional MuJoCo mutation drill; run `panda_sim` and `panda_mujoco`.
- Deliverable: the whole suite green with your own controller, and run C of `panda_mujoco` reproduced: the "damping felt" lines with final η̇ 0.0643, last 5 s max |ξ| 1.05e-02 and |β| 1.32e-02. That run is the baseline of tomorrow's work.

The drill copy has no `third_party/`, so point CMake at the project's MuJoCo and Menagerie, read-only (the runs of `panda_mujoco` take about 15 s in all):

```bash
cd ~/drills/se3pf
cmake -S . -B build-mj -DCMAKE_BUILD_TYPE=Release -DSE3PF_WITH_MUJOCO=ON \
    -DMUJOCO_DIR=$HOME/Desktop/SE3_pathFollowing/third_party/mujoco-3.15.0 \
    -DMENAGERIE_PANDA_DIR=$HOME/Desktop/SE3_pathFollowing/third_party/mujoco_menagerie/franka_emika_panda \
    -DFETCHCONTENT_SOURCE_DIR_CATCH2=$HOME/Desktop/SE3_pathFollowing/build/_deps/catch2-src
cmake --build build-mj -j8
./build-mj/tests_mujoco | tail -2
./build-mj/panda_mujoco out-mj | grep "damping felt"
```

### Day 10: extend the code (CTRL-1)

- Read: CTRL-1 in `TICKETS.md`; Project 1 in "Extension projects".
- Drills: implement the integral gains (default 0), the clamp, the integration after the ramp and the reset; write the tests listed in Project 1; run MuJoCo run C with your gains.
- Deliverable: a branch on which the 132 existing test cases pass unchanged and your new controller tests pass, plus a table of run C against the acceptance (last 5 s |ξ| < 1e-3, η̇ in [0.0784, 0.0816], every margin). Expect integral action alone to fall short. In the prototype, viscous compensation identified to 10 % plus integral action after the ramp passed: |ξ| 4.1e-4, η̇ 0.07936 to 0.08106. If you finish early, start Project 3 (the coupled lift), which reuses everything you rewrote this week.
