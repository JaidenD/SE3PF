### SO(3) and SE(3)

The hat map turns a 3-vector into the skew matrix of the cross product, and a twist into an element of se(3).

```latex
\hat\omega = \begin{bmatrix} 0 & -\omega_3 & \omega_2 \\ \omega_3 & 0 & -\omega_1 \\ -\omega_2 & \omega_1 & 0 \end{bmatrix},\qquad \hat\omega\,x = \omega\times x,\qquad \hat\zeta = \begin{bmatrix} \hat\omega & v \\ 0 & 0 \end{bmatrix},\qquad \zeta = (\omega, v)
```

Rodrigues' formula, with θ = ‖ω‖, is what `expSO3` evaluates from θ = 1e-8 up.

```latex
\exp(\hat\omega) = I + \frac{\sin\theta}{\theta}\,\hat\omega + \frac{1-\cos\theta}{\theta^2}\,\hat\omega^2
```

`logSO3` reads sin θ times the axis from the skew part, cos θ from the trace, and the angle from both. This is the formula for 1e-6 ≤ θ ≤ π − 1e-4.

```latex
s = \tfrac12\bigl(R - R^\top\bigr)^\vee = \sin\theta\; n,\qquad c = \tfrac12(\operatorname{tr}R - 1) = \cos\theta,\qquad \theta = \operatorname{atan2}(\|s\|,\ c),\qquad \log(R)^\vee = \frac{\theta}{\|s\|}\, s
```

Near π (θ > π − 1e-4), sin θ is tiny and s no longer carries the axis accurately. The symmetric part carries it instead, with a denominator near 2:

```latex
\tfrac12\bigl(R + R^\top\bigr) = \cos\theta\; I + (1-\cos\theta)\; n n^\top \quad\Longrightarrow\quad n n^\top = \frac{\tfrac12(R + R^\top) - c\,I}{1 - c},\qquad \log(R)^\vee = \theta\, n,\quad n^\top s \ge 0
```

The right Jacobian of exp and its inverse:

```latex
\frac{d}{dt}\exp\bigl(\hat\omega(t)\bigr) = \exp(\hat\omega)\,\bigl(J_r(\omega)\,\dot\omega\bigr)^\wedge,\qquad J_r(\omega) = I - \frac{1-\cos\theta}{\theta^2}\,\hat\omega + \frac{\theta-\sin\theta}{\theta^3}\,\hat\omega^2
```

```latex
J_r(\omega)^{-1} = I + \tfrac12\,\hat\omega + \Bigl(\frac{1}{\theta^2} - \frac{1+\cos\theta}{2\theta\sin\theta}\Bigr)\hat\omega^2
```

The small-angle branches replace each coefficient by the first terms of its Taylor series:

```latex
\exp(\hat\omega) \approx I + \hat\omega + \tfrac12\hat\omega^2\ (\theta < 10^{-8}),\qquad \log(R)^\vee \approx \Bigl(1 + \frac{\theta^2}{6}\Bigr)s\ (\theta < 10^{-6}),\qquad J_r \approx I - \tfrac12\hat\omega + \tfrac16\hat\omega^2,\qquad J_r^{-1} \approx I + \tfrac12\hat\omega + \tfrac1{12}\hat\omega^2\ (\theta < 10^{-6})
```

The adjoint maps, for g = (R, p) and ζ = (ω, v), in the (ω, v) order:

```latex
\mathrm{Ad}_g = \begin{bmatrix} R & 0 \\ \hat p\,R & R \end{bmatrix},\quad \mathrm{Ad}_g\zeta = \bigl(g\hat\zeta g^{-1}\bigr)^\vee,\qquad \mathrm{ad}_\zeta = \begin{bmatrix} \hat\omega & 0 \\ \hat v & \hat\omega \end{bmatrix},\quad \mathrm{ad}_a b = \bigl(\hat a\hat b - \hat b\hat a\bigr)^\vee
```

The lower-left block of Ad comes from multiplying out g ζ̂ g⁻¹:

```latex
g\hat\zeta g^{-1} = \begin{bmatrix} R\hat\omega R^\top & -R\hat\omega R^\top p + Rv \\ 0 & 0 \end{bmatrix},\qquad -(R\omega)\times p = p\times R\omega = \hat p R\,\omega
```

### The metric and its maps (Example 1)

```latex
W = \begin{bmatrix} w_R I_3 & 0 \\ 0 & w_p I_3 \end{bmatrix},\qquad \langle a, b\rangle_W = a^\top W b,\qquad \|a\|_W = \sqrt{a^\top W a},\qquad \ell = \sqrt{w_R / w_p}
```

```latex
\mathrm{Exp}_I(\hat\zeta) = \begin{bmatrix} \exp(\hat\omega) & v \\ 0 & 1 \end{bmatrix},\qquad \mathrm{Log}_I(g)^\vee = \bigl(\log(R)^\vee,\ p\bigr)\quad\text{for } \operatorname{tr}R > -1
```

The matrix exponential of ζ̂ (the screw motion) would put J_l(ω)v in the translation instead of v. For ζ = (0, 0, π/2, 1, 0, 0), Exp_I gives p = (1, 0, 0) and the matrix exponential gives (2/π)(1, 1, 0) = (0.6366, 0.6366, 0).

Γ is the body-coordinate derivative of Exp_I (eq:Gamma), and its inverse is block-wise:

```latex
\mathrm{Exp}_I(\zeta)^{-1}\,\frac{d}{dt}\mathrm{Exp}_I(\zeta + t\delta)\Big|_{t=0} = \bigl(\Gamma(\zeta)\,\delta\bigr)^\wedge,\qquad \Gamma(\zeta) = \begin{bmatrix} J_r(\omega) & 0 \\ 0 & \exp(\hat\omega)^\top \end{bmatrix},\qquad \Gamma(\zeta)^{-1} = \begin{bmatrix} J_r(\omega)^{-1} & 0 \\ 0 & \exp(\hat\omega) \end{bmatrix}
```

The distance (eq:dist) reduces, for the product type, to the relative rotation angle θ₁₂ and the Euclidean distance of the positions:

```latex
\operatorname{dist}(g_1, g_2) = \bigl\|\mathrm{Log}_I(g_1^{-1}g_2)^\vee\bigr\|_W = \sqrt{w_R\,\theta_{12}^2 + w_p\,\|p_2 - p_1\|^2},\qquad g_1^{-1}g_2 = \bigl(R_1^\top R_2,\ R_1^\top(p_2 - p_1)\bigr)
```

### The two paths

Each curve g(θ) = (R(θ), p(θ)) is written in its parameter θ with body velocity ζ̃(θ) = (g(θ)⁻¹ dg/dθ)^∨ = (ω̃, ṽ). For any attitude R(θ) and position p(θ), the translational parts follow from:

```latex
\tilde v = R^\top p',\qquad \tilde v' = \frac{d}{d\theta}\bigl(R^\top p'\bigr) = (R')^\top p' + R^\top p'' = -\hat{\tilde\omega}\,R^\top p' + R^\top p'' = R^\top p'' - \tilde\omega\times\tilde v
```

The coning circle (Panda example) tilts the rest attitude R₀ by the cone angle α. Since R_z(θ)AR_z(−θ) = exp(α(R_z(θ)e₁)^), the tilt axis (cos θ, sin θ, 0) of the frame R₀ turns once per revolution:

```latex
R(\theta) = R_0\,R_z(\theta)\,A\,R_z(-\theta),\quad A = \exp(\alpha\hat e_1),\qquad p(\theta) = p_0 + r(\cos\theta,\ \sin\theta,\ 0)
```

```latex
R^\top R' = R_z(\theta)\bigl[(A^\top e_3)^\wedge - \hat e_3\bigr]R_z(\theta)^\top \;\Longrightarrow\; \tilde\omega = R_z(\theta)\,w_0,\quad w_0 = A^\top e_3 - e_3,\qquad \tilde\omega' = R_z(\theta)\,(e_3\times w_0)
```

```latex
\|w_0\| = 2\sin(\alpha/2),\qquad \|\tilde v\| = r \quad\Longrightarrow\quad \sigma = \sqrt{4\,w_R\sin^2(\alpha/2) + w_p\,r^2}
```

With α = 0.25, r = 0.12 and w_R = 0.01 this is √(0.000621752 + 0.0144) = 0.1225632554. The rotation part contributes 4.1 % of σ²: at ℓ = 0.1 m the path is mostly a translation.

The tumbling circle (rigid-body example):

```latex
R(\theta) = \exp(\theta\hat e_1)\exp(\theta\hat e_3),\quad p(\theta) = r(\cos\theta,\ \sin\theta,\ 0),\qquad \tilde\omega = (\cos\theta,\ -\sin\theta,\ 1),\quad \tilde\omega' = (-\sin\theta,\ -\cos\theta,\ 0),\quad \sigma = \sqrt{2w_R + w_p r^2}
```

ω̃ follows from RᵀR′ = exp(−θê₃) ê₁ exp(θê₃) + ê₃ = (R_z(−θ)e₁)^ + ê₃. With W = I and r = 1, σ = √3 and ζ_γ(0) = (1, 0, 1, 0, 1, 0)/√3.

Arc length is a rescaling of θ because σ is constant:

```latex
s = \sigma\theta,\qquad L = 2\pi\sigma,\qquad \zeta_\gamma(s) = \frac{\tilde\zeta(\theta)}{\sigma},\qquad \zeta_\gamma'(s) = \frac{d\theta}{ds}\,\frac{\tilde\zeta'(\theta)}{\sigma} = \frac{\tilde\zeta'(\theta)}{\sigma^2}
```

### The spline

On interval k, with node spacing h = L/n and t = (s − s_k)/h ∈ [0, 1], the cubic Hermite interpolant and its s-derivative are:

```latex
y(s) = (2t^3 - 3t^2 + 1)\,y_k + (t^3 - 2t^2 + t)\,h\,y_k' + (-2t^3 + 3t^2)\,y_{k+1} + (t^3 - t^2)\,h\,y_{k+1}'
```

```latex
y'(s) = \frac{6t^2 - 6t}{h}\,y_k + (3t^2 - 4t + 1)\,y_k' + \frac{-6t^2 + 6t}{h}\,y_{k+1} + (3t^2 - 2t)\,y_{k+1}'
```

The basis polynomials are h₀₀ = 2t³ − 3t² + 1, h₁₀ = t³ − 2t² + t, h₀₁ = −2t³ + 3t² and h₁₁ = t³ − t². Each is the cubic with one end value or end slope equal to 1 and the other three zero: h₀₀(0) = 1, h₁₀′(0) = 1, h₀₁(1) = 1, h₁₁′(1) = 1. The factor h on the slopes converts d/dt into d/ds.

The error bounds explain the test thresholds:

```latex
|y(s) - f(s)| \le \frac{h^4}{384}\max|f^{(4)}|,\qquad |y'(s) - f'(s)| = O(h^3),\qquad \frac{y_{k-2} - 8y_{k-1} + 8y_{k+1} - y_{k+2}}{12h} - f'(s_k) = -\frac{h^4}{30}f^{(5)}(s_k) + O(h^6)
```

For the test function of `tests/test_spline.cpp` with n = 100 the bound gives 2.35e-7, and the measured value error is 2.348e-7.
